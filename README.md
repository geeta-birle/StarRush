# ⭐ StarRush

A fast-paced browser reaction game built with HTML, CSS, and JavaScript.

Test your reaction speed by clicking the moving star as many times as possible before the 10-second timer runs out.

## 🎮 Live Demo

🔗 star-rush-x8ch-32zfu3b4y-geetabirle-1357s-projects.vercel.app

## ✨ Features

- 🎯 Moving target gameplay
- ⏱️ 10-second countdown
- ⭐ Real-time score tracking
- 🔥 Combo multiplier system
- 🏆 Best score persistence using LocalStorage
- ✨ Interactive click animations
- 📱 Responsive design for desktop and mobile
- 🎨 Modern dark-themed UI
- 🔄 Instant replay functionality
- ⚡ No backend required

## 🕹️ How to Play

1. Click **Start Game**.
2. Find the moving ⭐ star.
3. Click the star as quickly as possible.
4. Every successful click increases your score.
5. Build your combo to earn bonus points.
6. Try to beat your highest score before the timer reaches zero.

## 📊 Scoring System

| Combo | Points per Click |
|------:|-----------------:|
| 0–4x | +1 |
| 5–9x | +2 |
| 10x+ | +3 |
